This is the architecture of ChaoticNotepad

The three layers: frontend/ (QML) talks to wrapper/ (Qt C++), and wrapper/ talks to backend/ (plain C++).
Left out: build/, build-release/, AppDir/, dist/ and tools/ (generated or downloaded, not part of the code).
(ChaoticNotepadMap.pdf shows how the parts connect.)

ChaoticNotepad/
├── .github/                            // GitHub settings
│   └── workflows/                      // what GitHub runs by itself
│       └── release.yml                 // on a pushed v* tag: builds on Ubuntu 22.04 with Qt 6.10.0, smoke-tests, publishes; run by hand it only builds
├── backend/                            // the plain C++ layer; everything in it is the text engine
│   └── textengine/                     // pure C++17 editor engine, no Qt: built as its own static library
│       ├── dialog/                     // the question box's logic
│       │   ├── dialog.h                // modal box with 2 or 3 buttons: which is selected and what each key does; drawing is up to the front end
│       │   └── dialog.cpp              // picks a button by key, first letter or click
│       ├── document/                   // one open file
│       │   ├── document.h              // the open file: path, saved text, line endings, BOM, encoding; open, save, reload, detects changes on disk
│       │   └── document.cpp            // loading, saving (a file always ends with a newline), indent detection, disk change checks
│       ├── filebrowser/                // the Open / Save As panel's logic
│       │   ├── filebrowser.h           // state of the panel: folder, filter or name, selection, keys, mouse; it never opens or writes files
│       │   └── filebrowser.cpp         // lists and sorts a folder, filters names, walks folders, handles Enter and double click
│       ├── fileIO/                     // files and paths
│       │   ├── fileio.h                // namespace FileIO: paths, read (50 MB limit by default), atomic write, encoding check, stat, FNV-1a hash
│       │   └── fileio.cpp              // built on std::filesystem; a save writes a temporary file and renames it over the target
│       ├── findpanel/                  // what the find bar shows
│       │   ├── findpanel.h             // namespace FindPanel: the buttons, the match counter text, which toggles are on; keeps no state
│       │   └── findpanel.cpp           // builds the button list and the counter text ("3 of 12", "No results")
│       ├── findreplace/                // searching
│       │   ├── findreplace.h           // searches a TextBuffer, keeps the match list, builds replacement text; only searches, TextView does the changing
│       │   └── findreplace.cpp         // plain search with case folding, regex through std::regex, $1 style replacement; stops at 100000 matches
│       ├── folding/                    // code folding
│       │   ├── folding.h               // finds foldable blocks (by brackets or by indentation) and keeps which are folded
│       │   └── folding.cpp             // region scanning, moves folds with the text, fold and unfold, hidden lines
│       ├── gutter/                     // line number text (the app does not use it)
│       │   ├── gutter.h                // namespace Gutter: width and label of a text line number column; nothing includes it, QML draws the gutter
│       │   └── gutter.cpp              // the column width and the " 12 │" style label
│       ├── gutterstyle/                // change marks
│       │   ├── gutterstyle.h           // tracks which lines are unsaved, saved-changed or untouched; read for the gutter and the minimap
│       │   └── gutterstyle.cpp         // compares the current text with the opened and the saved text
│       ├── inputevents/                // input types
│       │   └── inputevents.h           // key, text, paste and mouse event types that a front end turns its own events into
│       ├── inputHandler/               // what each input does
│       │   ├── inputhandler.h          // input modes, InputState, Requests to the program (save, open, tabs...), and the handleEvent entry points
│       │   └── inputhandler.cpp        // key bindings, and how text, find bar and file browser react to keys and the mouse
│       ├── minimap/                    // the minimap's numbers
│       │   ├── minimap.h               // computes the minimap picture, marks and scroll maths; draws nothing
│       │   └── minimap.cpp             // builds the picture, converts rows and lines, sets the marks
│       ├── multicursor/                // cursors
│       │   ├── multicursor.h           // the Cursor type (caret and selection) and namespace MultiCursor
│       │   └── multicursor.cpp         // sorts the cursors and merges the ones that overlap or touch
│       ├── stickyscroll/               // pinned header lines
│       │   ├── stickyscroll.h          // decides which block header lines stay pinned at the top; draws nothing
│       │   └── stickyscroll.cpp        // builds the scope tree and works out the pinned lines
│       ├── syntaxhighlight/            // syntax colours: one scanner, one definition per language
│       │   ├── cmakesyntax.h           // declares the CMake definition and registers it
│       │   ├── cmakesyntax.cpp         // CMake definition: .cmake and CMakeLists.txt
│       │   ├── cppsyntax.h             // declares the C/C++ definition and registers it
│       │   ├── cppsyntax.cpp           // C/C++ definition: .c .h .cpp .cc .cxx .hpp .hh .hxx .ino
│       │   ├── fishsyntax.h            // declares the fish definition and registers it
│       │   ├── fishsyntax.cpp          // fish shell definition: .fish
│       │   ├── jssyntax.h              // declares the JavaScript definition and registers it
│       │   ├── jssyntax.cpp            // JavaScript definition: .js .mjs .cjs .jsx
│       │   ├── languagedef.h           // the Token kinds, the format of a language definition, registerLanguage and findLanguage
│       │   ├── luasyntax.h             // declares the Lua definition and registers it
│       │   ├── luasyntax.cpp           // Lua definition: .lua .rockspec
│       │   ├── qmlsyntax.h             // declares the QML definition and registers it
│       │   ├── qmlsyntax.cpp           // QML definition: .qml
│       │   ├── rustsyntax.h            // declares the Rust definition and registers it
│       │   ├── rustsyntax.cpp          // Rust definition: .rs
│       │   ├── shsyntax.h              // declares the shell definition and registers it
│       │   ├── shsyntax.cpp            // shell definition: .sh .bash .zsh .ksh and files such as .bashrc
│       │   ├── syntaxhighlighter.h     // gives every byte of the text a token; includes all eight language headers
│       │   └── syntaxhighlighter.cpp   // the language list and the line scanner, which carries comment and string state between lines
│       ├── tabbar/                     // tab strip for a terminal front end (the app does not use it)
│       │   ├── tabbar.h                // tab strip in character columns; nothing includes it, QML draws its own tabs
│       │   └── tabbar.cpp              // column layout, hit testing and drag reordering
│       ├── tabs/                       // the open tabs
│       │   ├── tabmanager.h            // EditorTab (TextView, Document, GutterStyle, SyntaxHighlighter) and TabManager, which holds them all
│       │   └── tabmanager.cpp          // new, open, close, reopen, switch, move and reload tabs
│       ├── textbuffer/                 // the text itself
│       │   ├── textbuffer.h            // the text as a list of lines, Position, UTF-8 helpers and a revision number
│       │   └── textbuffer.cpp          // insert, erase, offsets and clamping
│       ├── textstats/                  // counting
│       │   ├── textstats.h             // text counts: characters, words, lines, paragraphs, reading time
│       │   └── textstats.cpp           // does the counting
│       ├── textstyle/                  // character formatting
│       │   ├── textstyle.h             // per-character bold, italic, underline and font size, laid out like the TextBuffer
│       │   └── textstyle.cpp           // keeps the styles in step with the text and applies formatting to ranges
│       ├── textview/                   // the main editing class
│       │   ├── textview.h              // the class the UI talks to: owns the buffer, cursors, formatting, undo history, find state and folds
│       │   └── textview.cpp            // all editing, cursor movement, find and replace, line operations, stateRevision
│       ├── undohistory/                // undo and redo
│       │   ├── undohistory.h           // undo and redo steps kept as small changes, not copies of the text
│       │   └── undohistory.cpp         // the two step stacks, trimmed to 200 steps or 256 MB by default
│       └── wordwrap/                   // line wrapping
│           ├── wordwrap.h              // splits lines into screen rows and converts positions to rows and back
│           └── wordwrap.cpp            // the wrap layout
├── EducationPurpose/                   // this explanation of the project
│   ├── architecture.txt                // this file: the project tree, one line per file and folder
│   └── ChaoticNotepadMap.pdf           // diagrams: how frontend, wrapper and backend connect, one keystroke, start-up, releasing
├── frontend/                           // everything you see: the QML screens, the look and the icon font
│   ├── editor/                         // the text area
│   │   ├── CodeEditor.qml              // text rows, pinned lines, cursor blink, mouse and keyboard; draws what it is given, never edits text
│   │   └── EditorRow.qml               // one drawn row: selection, find matches, brackets, coloured text, fold pill, cursors
│   ├── filebrowserdialog/              // the Open / Save As box
│   │   └── FileBrowserDialog.qml       // lists one folder at a time; pick a file (Open) or type a name (Save As)
│   ├── find/                           // the find bar
│   │   └── FindReplaceBar.qml          // find and replace bar under the text: fields, counter, options, Replace buttons
│   ├── fonts/                          // font built into the app
│   │   └── fa-solid-900.ttf            // Font Awesome 6 Free Solid, the icon font
│   ├── gutter/                         // the line number column
│   │   ├── Gutter.qml                  // line numbers, fold arrows and change marks, scrolled with the text
│   │   └── GutterCell.qml              // one gutter row: change mark, fold arrow, line number
│   ├── minimap/                        // the minimap
│   │   └── Minimap.qml                 // whole-file overview: shaded visible part, mark strips, click or drag to scroll
│   ├── promptdialog/                   // the question box
│   │   └── PromptDialog.qml            // draws the 2 or 3 button question: unsaved changes, file changed on disk, save conflict
│   ├── settingsdialog/                 // the Settings window
│   │   ├── FontListPanel.qml           // searchable list of the installed fonts
│   │   ├── SettingsDialog.qml          // the settings panel; also binds font and dark mode to Theme
│   │   ├── SettingsRow.qml             // one line: title, explanation and a control
│   │   ├── SettingsStepper.qml         // a number with minus and plus buttons
│   │   └── SettingsSwitch.qml          // on / off switch
│   ├── shortcutsdialog/                // the Shortcuts window
│   │   └── ShortcutsDialog.qml         // lists every shortcut; click one and press new keys; restore defaults
│   ├── statusbar/                      // the status bar
│   │   └── BottomStatusbar.qml         // latest message, then counts, position, indent, encoding, line ending, language
│   ├── tabbar/                         // the tab strip
│   │   ├── DocumentTab.qml             // one tab: title, unsaved dot or close button, click and drag
│   │   └── DocumentTabBar.qml          // row of tabs with "+", drag reordering and wheel scrolling
│   ├── toolbar/                        // the bottom bar
│   │   ├── BottomToolbar.qml           // New, Open, Save, Save As, Undo, Redo, Find, Shortcuts, Settings; only reports clicks
│   │   └── ToolbarButton.qml           // one toolbar button: icon and label
│   ├── Icon.qml                        // singleton: every icon as a glyph of the icon font, by name
│   └── Theme.qml                       // singleton: every colour and size, dark and light, syntax colours, editor font
├── importedcontent/                    // meant for a design downloaded from Figma to Qt; holds only its README
│   └── README.md                       // says to save a Figma design here; CMakeLists.txt does not actually read this folder
├── packaging/                          // making and installing the release files
│   ├── build-appimage.sh               // builds the app, then the AppImage, the tar.xz and SHA256SUMS.txt in dist/
│   ├── install-app.sh                  // inside the tar.xz: installs for the current user, no root
│   └── uninstall-app.sh                // removes what install-app.sh installed; documents and settings stay
├── wrapper/                            // Qt C++ layer between QML and the engine: controllers and list models
│   ├── browser/                        // the file browser for QML
│   │   ├── browsercontroller.h         // shows the engine's file browser to QML, passes keys and clicks back (BrowserController)
│   │   └── browsercontroller.cpp       // copies the browser state after every change; its buttons go through EditorController
│   ├── dialog/                         // the question box for QML
│   │   ├── dialogcontroller.h          // holds the engine Dialog and the questions the program asks (DialogController)
│   │   └── dialogcontroller.cpp        // closing, quitting, save conflicts; a 1 second timer checks the open file for outside changes
│   ├── editor/                         // the hub
│   │   ├── editorcontroller.h          // owns tabs, input state, row builder and sticky scroll; every key and click passes through it (EditorController)
│   │   ├── editorcontroller.cpp        // turns Qt events into engine events, carries out the engine's requests, rebuilds the rows
│   │   ├── editorrowsmodel.h           // list model of the rows the text area draws; owns no text (EditorRowsModel)
│   │   ├── editorrowsmodel.cpp         // asks RowBuilder for a row when QML asks, keeps the last answer
│   │   ├── rowbuilder.h                // turns the current tab into rows: spans, selection, cursors, matches, gutter data; no Qt in it (RowBuilder)
│   │   └── rowbuilder.cpp              // wrapping and folds to rows, character widths in cells, mouse position to text position, pinned rows
│   ├── find/                           // the find bar for QML
│   │   ├── findcontroller.h            // keeps the engine's find state in step with the bar (FindController)
│   │   └── findcontroller.cpp          // runs searches and replaces on the TextView; counter text comes from the engine FindPanel
│   ├── gutter/                         // the gutter for QML
│   │   ├── guttercontroller.h          // gives the gutter its rows and digits, passes clicks back (GutterController)
│   │   ├── guttercontroller.cpp        // refreshes on rowsRebuilt and stickyChanged from EditorController
│   │   ├── guttermodel.h               // list model of gutter rows, same rows and order as the text area (GutterModel)
│   │   └── guttermodel.cpp             // asks RowBuilder for a row when QML asks, keeps the last answer
│   ├── minimap/                        // the minimap for QML
│   │   ├── minimapcontroller.h         // owns the engine Minimap; position, marks, clicks and dragging for QML (MinimapController)
│   │   ├── minimapcontroller.cpp       // groups changes with a zero-length timer, updates the picture, marks and viewport
│   │   ├── minimappicture.h            // QML item that draws the minimap cells (MinimapPicture)
│   │   └── minimappicture.cpp          // paint(): one small square per cell, coloured by syntax token
│   ├── settings/                       // settings for QML
│   │   ├── settingscontroller.h        // theme, font, indent, bracket closing and minimap switch (SettingsController)
│   │   └── settingscontroller.cpp      // reads and writes QSettings, applies bracket closing to every tab, and indent to tabs without their own
│   ├── shortcuts/                      // keyboard shortcuts for QML
│   │   ├── shortcutscontroller.h       // the shortcut list and the keys you chose (ShortcutsController)
│   │   └── shortcutscontroller.cpp     // builds the list, turns a changed key back into the engine's built-in key, saves in QSettings
│   ├── status/                         // the status bar for QML
│   │   ├── statuscontroller.h          // what the status bar shows; only reads, never changes the engine (StatusController)
│   │   └── statuscontroller.cpp        // reads the current tab after every change; counts lines, words and paragraphs itself
│   └── tabs/                           // the tab strip for QML
│       ├── tabscontroller.h            // TabsModel (title and unsaved state of each tab) and TabsController
│       └── tabscontroller.cpp          // keeps the model in step with TabManager; select, close, new and move
├── .gitignore                          // what git leaves out: build output, packaging tools, caches, editor files
├── ChaoticNotepad.desktop              // the app menu entry
├── ChaoticNotepad.svg                  // the app icon
├── CMakeLists.txt                      // the build: textengine library, app and QML module, Qt 6.10 or newer, install rules, version 2.0
├── Features.txt                        // feature list of version 2.0
├── install.sh                          // as root: builds and installs into /usr/local
├── LICENSE                             // the GNU GPL v3 license
├── main.cpp                            // start of the program: creates the app, loads Main.qml, opens files named on the command line
├── Main.qml                            // the window: tab bar, gutter + text + minimap, find bar, status bar, toolbar, all dialogs, dropped files
├── README.md                           // what the app is, how to install, build and uninstall it, the features
└── uninstall.sh                        // as root: removes the install.sh install from /usr/local
